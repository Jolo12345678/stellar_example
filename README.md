# RiceChain
Instant cash-advances for smallholder supply chain farmers.

## Problem & Solution
Rice farmers in Nueva Ecija, Philippines face severe 4-week cash flow delays from buyers, exposing them to predatory lenders. RiceChain allows buyers to execute instant, low-fee USDC advances through Soroban escrow architectures directly to a farmer's wallet immediately upon crop arrival.

## Timeline
Developed within a 48-hour hackathon timeline.

## Stellar Features Used
- Soroban Smart Contracts (Escrow Execution)
- Stellar Asset Token Rails (USDC Payouts)

## Vision and Purpose
To dismantle structural debt dependencies among agricultural producers across Southeast Asia using friction-free value rails.

## Prerequisites
- Rust (v1.75+)
- Soroban CLI (v21.0.0+)
